# Product

## Register

product

## Users

Mogplex serves technical and technical-adjacent operators who use AI agents to work on real repositories. They need to understand what code, compute, task, and repository context an agent is using without needing deep knowledge of Git or infrastructure terminology.

## Product Purpose

Mogplex brings agent chat, code, terminal, preview, automation, and run telemetry into one repo-bound workspace. Success means an operator can move from a repository and an intended outcome to verified, reviewable work while retaining clear control over execution context, lifecycle, and consequences.

## Brand Personality

Precise, calm, and capable. The product should communicate operational truth directly, use concise language, and make sophisticated workflows feel trustworthy rather than theatrical.

## Anti-references

Do not resemble a decorative AI demo, a disconnected chatbot, or a Git client that obscures runtime behavior. Avoid novelty affordances, ornamental motion, broad visual churn, and labels or icons that collapse distinct resources into one concept.

## Design Principles

- Teach the object model where users encounter it.
- Make resource identity, state, ownership, and lifecycle consequences explicit.
- Preserve familiar product patterns so the interface disappears into the task.
- Show the exact selected context that actions and agents will use.
- Prefer concise operational truth over decorative explanation.

## Accessibility & Inclusion

Use semantic controls, keyboard-accessible interactions, visible focus, accessible names and descriptions, and state communication that does not rely on color alone. Copy must remain understandable to operators who do not already know Git worktree terminology. Responsive layouts must preserve meaning and action consequences at narrow widths.
